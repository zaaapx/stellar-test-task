# Jeorjett Dress — редизайн картки товару J-1165

Тестове завдання (CRO & e-commerce): редизайн сторінки весільної сукні.

- `index.html` — картка товару (desktop 1440 / mobile 375).
- `fitting.html` — список примірки: до 5 суконь, вибір кольору й розміру, запис у салон (місто і салон → дата і час → контакти).
- `assets/site.css`, `assets/site.js` — спільні стилі, хедер, обране і список примірки (зберігається в localStorage); `assets/booking.js` — логіка сторінки примірки.
- Основна цільова дія — додати сукню до примірки й записатися; ціна роздрібна, оптовий вхід — окремою кнопкою.

Відкрити: просто відкрийте `index.html` у браузері або увімкніть GitHub Pages (Settings → Pages → гілка `main`).

Фото взяті з сайтів LuceSposa та Jeorjett і підвантажуються за посиланнями. Ціни, рейтинг, відгуки та наявність розмірів — демонстраційні.

## Дизайн-система (Figma ↔ HTML)

- Шрифт: **Raleway** (Google Fonts) — повна підтримка української (Є, І, Ї, Ґ); у CSS увімкнені лінійні цифри (`font-variant-numeric: lining-nums`).
- Кольори, відступи, радіуси, розміри іконок і шрифтів — змінні Figma (колекції Color, Typography, Spacing, Size, Effects); у CSS — токени в `:root` в `assets/site.css`.
- Усі тексти в макетах прив’язані до текстових стилів, повторювані елементи — компоненти (UI Kit, сторінка «UI Kit» у Figma).
- Обов’язкові поля форм позначені `*`.
- Сторінки Figma: «Item preview page» — картка товару; «Fitting page» — список примірки та запис; «UI Kit».
